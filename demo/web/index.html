Give it a real challenge

At a 50 MHz host clock the chip's default divider gives one sample per 1 ms; the 1–8 sample setting gives a nominal 1–8 ms threshold. This simulator accelerates the divider to 4 cycles per sample. A real sensor's pulse widths still need measurement.

Controls define a generated signal, not measured sensor data.
